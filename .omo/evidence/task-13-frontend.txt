## Typed invoke wrappers (src/lib/api.ts) — match T12 contract exactly
- unlock(password) / lock() / getSessionStatus() -> { unlocked, device_id }
- list() / get(id) / create(input) / update(id, input) / deleteEntry(id) [invokes "delete";
  `delete` is a reserved word in JS] / search(q) -> Entry[]
- copy(field: "password"|"username"|"url", id) / generatePassword(length) -> string
- syncNow() -> { pushed, pulled, merged, backup_created: string|null }
- getSyncConfig() -> { remote_url } | null / setSyncConfig(remoteUrl, pat)
- Tauri 2 maps camelCase JS args to snake_case Rust params automatically (remoteUrl -> remote_url).
- Backend errors reject with Chinese strings ("密码错误", "请先解锁", "保险库文件不存在", ...)
  surfaced directly in the UI (no translation layer).
