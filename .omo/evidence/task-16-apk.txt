## Build journey (blockers hit and resolved)
1. OOM kills (3.8Gi box) → CARGO_BUILD_JOBS=2 + gradle jvmargs -Xmx1024m + setsid nohup.
2. openssl-sys make: "aarch64-linux-android-ranlib: not found" → created /tmp/ndk-bin
   symlinks for all 4 ABI triples + exported CC/AR/RANLIB_<triple> env vars.
3. gradle rustBuild task: "Cannot find module /home/ubuntu/passm/src-tauri/tauri" →
   src-tauri/tauri must be a symlink to ../node_modules/@tauri-apps/cli/tauri.js
   (node shim file fails: project is ESM; require() throws).
4. gradle wrapper distribution download failed (Java SSL + curl CDN both blocked) →
   user manually downloaded gradle-8.14.3-bin.zip (137 MB); placed in
   ~/.gradle/wrapper/dists/gradle-8.14.3-bin/cv11ve7ro1n3o1j4so8xd9n66/.
5. x86_64/armv7/i686 openssl asm breakage → arm64-only build (-t aarch64).
6. Tauri release buildType has no signingConfig → unsigned APK → manual apksigner sign
   with debug keystore (per plan v1: debug signing only).
