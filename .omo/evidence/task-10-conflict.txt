DESIGN NOTES
------------
- Salt invariant (T6): conflict merge re-encrypts with envelope::parse_header
  (local_blob) -> params + salt; only the nonce is fresh. A fresh salt would
  change the derived key and the password could no longer unlock the vault.
- TWO-PARENT MERGE COMMIT is required for retry convergence: a push only
  succeeds when the local branch is a descendant of the remote branch. If the
  conflict-resolution commit only had the local head as parent, a rejected push
  (remote advanced concurrently) would re-merge forever on top of the stale
  local branch and never become a descendant of the remote -> SyncRetryExhausted
  even though the remote stopped advancing. Adopting the remote head as the
  second parent makes the next push a fast-forward.
- libgit2 (vendored) has NO receive-pack / server hooks, so the pre-receive-hook
  retry simulation is impossible; used a #[cfg(test)] PRE_PUSH hook
  (Mutex<Option<Arc<dyn Fn() + Send + Sync>>>) installed via run_pre_push_hook.
  The hook is CLONED out of the mutex before invoking so a hook may clear
  itself (set PRE_PUSH = None) without deadlocking.
- Module-global REPO_DIR (T9) means multi-device tests must re-point it before
  EACH device's operation block: ensure_clone(&url, &local_x) before every
  write/commit/push/sync for device x. Forgetting this makes device A's writes
  land in device B's repo (silent cross-device corruption in tests).
- remote_head() on an empty clone: repo.head() errors with UnbornBranch; the
  HEAD symbolic target ("refs/heads/master") is read instead, so the tracking
  ref refs/remotes/origin/<branch> is found after the first fetch.
- git2 0.21 Reference::symbolic_target() returns Result<Option<&str>, Error>
  (not Option) - needs .ok()?? to extract.
- canonical_json() sorts entries by id, so decrypted blobs compare equal to
  expected Vaults only via canonical_json() (or titles()), not Vault PartialEq.
- Device A's post-merge sync is a FAST-FORWARD PULL (its v3 is an ancestor of
  the merge commit), not a second merge - commutativity holds on vault content.
