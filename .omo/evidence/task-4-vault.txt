=== Model (crates/passm-vault/src/lib.rs) ===
Entry { id: Uuid, title, username, password, url, notes, version: u64,
        device_id, created_at: i64, updated_at: i64, deleted: bool }
Vault { entries: Vec<Entry> }
- serde derive on both; struct field order = stable JSON key order.
- Entry::new(...) -> version=1, created_at/updated_at=now (SystemTime unix secs),
  deleted=false, id=Uuid::new_v4().
- Entry::bump() -> version+=1, updated_at=now.
- Entry::mark_deleted() -> deleted=true (tombstone).
- Vault::empty() -> {"entries":[]} (first-run bootstrap).
- Vault::canonical_json() -> Vec<u8>: serde_json::to_vec of a Vault whose
  entries are sorted by id (stable byte output for T5 merge convergence).
- No HashMap anywhere in serialization; timestamps are i64 unix secs, not String.
