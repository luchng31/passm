API (src-tauri/src/session.rs)
------------------------------
- SessionState { vault_key: Option<Zeroizing<[u8;32]>>, vault: Option<Vault>,
  device_id: String, unlocked_at: Option<u64> } — in-memory only, never persisted.
  vault_key is zeroized on drop via Zeroizing; lock_session drops key+vault and
  clears unlocked_at.
- Pure fns (no Tauri runtime, unit-testable):
  * unlock_session(state, key, vault, now) — stores key (Zeroizing), vault, stamps
    unlocked_at. NOT yet wired to a command (T12 unlock flow); carries
    #[expect(dead_code)] until then.
  * lock_session(state) — drops key (zeroized) + vault, clears unlocked_at.
  * should_auto_lock(state, now, timeout_secs) — true iff unlocked and
    unlocked_at.saturating_add(timeout_secs) <= now. Locked session never auto-locks.
- Clock trait { now_unix() } + SystemClock (wall clock via SystemTime/UNIX_EPOCH)
  so auto-lock timing is testable without sleeps.
- AUTO_LOCK_TIMEOUT_SECS = 300 (5 min), check interval 30s.

Tauri wiring (src-tauri/src/lib.rs)
-----------------------------------
- Commands: `lock` (zeroizes key via lock_session_state), `get_session_status`
  (returns { unlocked, device_id } — no secrets). Registered via generate_handler!.
- Tray: MenuItem::with_id("show"/"lock"/"quit") + on_menu_event match on
  event.id().as_ref(); left-click on tray icon (TrayIconEvent::Click, Left/Up)
  shows the main window. show_menu_on_left_click(false).
- Auto-lock: background thread sleeps 30s, checks should_auto_lock with
  SystemClock.now_unix(), locks when due.
- AppPaths { data_dir: PathBuf } resolved once in setup via
  app.path().app_data_dir() and managed (T12 repo/backups/device_id live under it).
- tauri_plugin_clipboard_manager::init() registered.
- SessionState managed as tauri::State<Mutex<SessionState>>; poisoned mutexes
  recovered via unwrap_or_else(|p| p.into_inner()) — no panics in non-test code.
