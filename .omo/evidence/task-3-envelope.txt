=== Byte layout (verified by header_layout_is_byte_exact) ===
bytes 0..5   magic b"PASSM1"
byte  6      version 0x01
bytes 7..10  mem_kib u32 BE
bytes 11..14 iterations u32 BE
bytes 15..18 parallelism u32 BE
bytes 19..50 salt (32B)
bytes 51..74 nonce (24B, fresh OsRng per encrypt)
bytes 75..   ciphertext || 16B Poly1305 tag
AAD = bytes 0..74 inclusive (entire 75-byte header)

=== Notes ===
- chacha20poly1305 0.11: XNonce = Array<u8, U24>; Key = Array<u8, U32>.
  from_slice() is DEPRECATED in hybrid-array 0.4.14 -> used From<[u8; N]> instead
  (XNonce::from([u8;24]), Key::from([u8;32])), same 24B/32B semantics.
- encrypt() -> Vec<u8> (spec signature, not Result): aead::Error is provably
  unreachable for in-memory payloads (only fails >= 256 GiB or AAD > u64::MAX);
  handled with match + unreachable! + # Panics doc, matching T2 derive_vault_key precedent.
- Enabled chacha20poly1305 "zeroize" feature at member level (key hygiene: wipes
  cipher's internal key copy on drop). Workspace dep unchanged.
- decrypt() parses header via parse_header() (magic/version/length validated) then
  AEAD-decrypts with AAD = blob[..75]; nonce read from bytes 51..75.
- No unwrap/panic in non-test code. No logging of keys/ciphertext/plaintext.
